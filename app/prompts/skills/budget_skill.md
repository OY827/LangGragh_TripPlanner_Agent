# 预算计算技能

## 功能
帮助 Agent 计算和展示旅行预算。

## 使用场景
- 生成旅行计划时
- 用户询问费用预估时

## 处理逻辑
1. 收集各景点门票价格
2. 估算每日餐饮费用（早餐30-50元，午餐50-100元，晚餐80-150元）
3. 根据住宿类型估算酒店费用（经济型200-400元/晚，舒适型400-800元/晚，豪华型800-2000元/晚）
4. 估算交通费用（市内交通50-100元/天）
5. 汇总各项费用，生成预算报告

## 输出格式
- total_attractions: 景点门票总计
- total_hotels: 酒店住宿总计
- total_meals: 餐饮费用总计
- total_transportation: 交通费用总计
- total: 总预算
